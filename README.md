💖 Matrix Rain Effect

Bu proje, HTML, CSS ve JavaScript kullanılarak hazırlanmış neon bir kalp animasyonu ile birlikte Matrix tarzı yazı yağmuru efektini içeren görsel bir gösterimdir. Hem estetik hem de interaktif bir animasyon deneyimi sunar.

✨ Özellikler

💓 Kalp şeklinde animasyonlu neon efekt
🟣 Matrix tarzı akan karakterler
💻 Tam ekran ve responsive yapı
🎨 CSS ile yaratıcı animasyonlar
🔧 Kullanılan Teknolojiler

HTML5
CSS3
JavaScript
